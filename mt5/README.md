# اجرای اسکریپت‌ها در MetaTrader 5 (حساب دمو)

این اسکریپت‌ها هنوز **کامپایل نشده‌اند**. خطاهای کامپایل را همان‌طور که MetaEditor نشان می‌دهد برای من بفرستید تا اصلاح کنم. هیچ‌کدام سفارشی ارسال نمی‌کنند.

## ۱. آماده‌سازی
1. در LiteFinance یک **حساب دموی ECN روی MT5** باز کنید و با آن وارد متاتریدر شوید.
2. در متاتریدر: منوی File و سپس Open Data Folder را بزنید. پوشه‌ای به نام `MQL5` باز می‌شود.
3. فایل‌ها را کپی کنید:
   - `mt5/Scripts/DataProbe.mq5` و `mt5/Scripts/SizingSelfTest.mq5` به `MQL5\Scripts`
   - `mt5/Include/RiskSizing.mqh` به `MQL5\Include`
4. در MetaEditor (کلید F4) هر اسکریپت را باز کنید و Compile (کلید F7) را بزنید. پیام‌های بخش Errors را ذخیره کنید.

## ۲. بررسی داده (DataProbe)
1. در Market Watch، نمادهای XAUUSD و EURUSD را فعال کنید.
2. DataProbe را از پنجرهٔ Navigator روی یک نمودار بکشید. ورودی‌های پیش‌فرض کافی است.
3. اسکریپت برای هر نماد حدود ۲ دقیقه عمق بازار را نمونه‌برداری می‌کند؛ کل اجرا حدود ۵ دقیقه طول می‌کشد. بهتر است در ساعات فعال بازار، مثلاً جلسهٔ لندن یا نیویورک، اجرا شود.
4. در پایان، مسیر فایل در زبانهٔ Experts نوشته می‌شود: `...\Common\Files\data_probe.json`.
5. **اختیاری ولی مفید:** یک معاملهٔ ۰٫۰۱ لات روی هر نماد در حساب دمو باز و بسته کنید و اسکریپت را دوباره اجرا کنید. این کار کمیسیون واقعی را اندازه‌گیری می‌کند.
6. محتوای `data_probe.json` را برای من بفرستید. طبقه‌بندی با این دستور انجام می‌شود:
   ```
   python -m bot.probe_classify data_probe.json
   ```

## ۳. خودآزمایی محاسبهٔ حجم (SizingSelfTest)
1. فایل `tests/vectors/sizing_vectors.csv` را در پوشهٔ `Common\Files` کپی کنید. مسیر این پوشه در خروجی DataProbe چاپ شده است.
2. SizingSelfTest را اجرا کنید. خروجی درست این است:
   ```
   SizingSelfTest: 17 cases, 0 failed
   ```
